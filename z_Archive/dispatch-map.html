The loop

One door, with an exception

Calling an agent by name works and skips the framing — prody’s own rule is to stay quiet when you’ve already chosen. What you skip is the closing review, which is the part that compounds.

Climb only as far as needed

Inline is the default rung; a single specialist is the next; a pipeline is for work that will be merged, shipped, or put in front of leadership. Each rung costs a cold start and a context reload.

Two graders, two subjects

agent-improver grades the agent that did the work. watchdog grades the work itself for duplication and drift. Running only one leaves the other gap uncovered.

Skills instead of agents

An agent is a subagent with its own context window and tool set. A skill is instructions loaded into the current turn — no separate context, no dispatch. Prody’s routing table, current as of 2026-08-17, sends six distinct named cases to a skill instead of an agent. Where this replaced an agent

The agent-router agent was retired 2026-08-15 and archived unmodified at ~/.claude/skills/_retired/agent-router/SKILL.md; its routing method was folded into prody. The one thing it did that prody cannot: auto-trigger on description match with no explicit invocation. Prody has to be launched.

Skill before agent, not instead of checking

“Before embodying a role that has a canonical skill behind it, check the session’s skill listing” — running the skill beats paraphrasing the agent file from memory. This rung was being skipped entirely until 2026-08-17.

Filesystem is a cross-check, not proof

multi-actor-research, multi-actor-strategy, red-team, first-principles, issue-tree, and prompt-refiner are local, editable skills on disk, so a filesystem hit is a valid second check for them. Genuine plugin skills never appear on disk — a miss there proves nothing either way.

Inside the two pipelines

Which model each agent runs on

The tier tracks what the agent produces that nothing downstream checks. Not seniority, not how important the agent feels. If a later actor grades the work against something fixed — a spec, a rubric, a test suite — the work is bounded and sonnet is the right call. If the agent’s output becomes the thing everything else is measured against, or if it arbitrates between other agents, an error there is invisible to every check that follows, and that is what opus is for.

That principle skews this library heavily toward opus — 14 of 20 as of 2026-08-17, four of them moved there this session after independent verification — and the reason is worth saying out loud: this is a library of checkers and arbiters, not producers. Only six agents in it do bounded work against a fixed target. If the ratio looks wrong, the fix is a different library, not a cheaper tier on an unchecked judgment call.

opus — nothing checks it

Framing, arbitration at impasse, adversarial attack, composition, and any grading pass. The hub, both orchestrators, both graders, and every actor holding decision rights.

sonnet — a downstream actor checks it

Implementation against an approved spec, execution and reporting, read-only passes that cannot edit, and translation that a grader has already qualified.

haiku — currently unused, correctly

No agent here is mechanical enough. The cheapest work in the library is code-improver, which still has to judge what counts as an improvement. fable is likewise reserved, not routine.

The arrows are real

Settled 2026-08-16

For five weeks, every arrow in the first diagram might have been running inside a single context. Both orchestrators and prody delegate to real subagents when the Agent tool is reachable, and otherwise embody each role themselves — and every work-sample review in CHANGELOG.md carried a reduced-independence caveat, because the tool never had been reachable. The library’s central premise, separate contexts producing independent judgement, had never once been observed to execute.

It has now. A deliberate agent-improver dispatch returned a genuine delegate, which reviewed prody’s new portfolio section and reported — unprompted and literally — that it could see no conversation prior to its brief. It found eight problems with the section, two of which were confirmed by measurement: the frontmatter was 1,581 characters against a 1,024 limit, and the improvement queue it had just been granted had no receiving end, because agent-improver contained no instruction to read it.

So the twelve pipeline actor files earn their maintenance, the argument for collapsing them into staged prompts is withdrawn, and the concurrency in the second diagram is a real capability rather than a documented aspiration. Reachability still varies by environment, which is why prody’s launch step now probes for it rather than assuming it — and why the honest word for what ran, delegated or embodied, is now something every run has to state.
