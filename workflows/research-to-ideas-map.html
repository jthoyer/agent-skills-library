Research to Ideas: agents and workflow

Version 3 of the pipeline. The main thread runs nine stages, 0 to 8, and makes every call. Four agents and one script attach where the main thread was grading its own work. Lite runs skip the agents.

What each piece fixes

  • Auditor: the author no longer grades their own evidence. Where the two grades differ, the lower one stands.
  • Scout: a missing source class becomes a task, not just a cap on confidence.
  • Analysts: the fifth cluster gets the same depth as the first.
  • Challenger: the person who ranked an idea does not stress-test it. A Blocks verdict drops the idea to Low.
  • check_brief.py: totals, confidence caps, the ranking rule and decision-rule gaps run in a second, not by eye. Its own tests run in CI.
  • Calibration: a re-run compares predicted confidence and ranges to what happened.
  • Run checklist: the main thread pastes a nine-line checklist (stages 0–8) into its reply and ticks each stage as it closes. A stage starts only when the one above is ticked. Added 2 Oct 2026.

No agent tool in the session? Each role runs inline, the run is labelled embodied, and confidence caps at Medium. The scout and analyst have a retire test: after two real runs, if the main thread would have produced the same output, drop them.
