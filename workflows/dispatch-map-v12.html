Dispatch Map v12

Eighteen agents and thirty-nine skills, all edited in this repo and nowhere else. Every request enters one front door: /rewrite launches the cpo skill in the main thread. It frames the request, routes it to the lowest rung that fits, dispatches real agents, and reviews the work after. Every conductor is a skill, and a hook runs CI before every push.

What each agent guarantees

The three conductors, cpo, cos and mc-orchestrator, are skills and sit outside this table. Every row below is an executor.

What changed since v11 (2026-10-23)

  • Verify recipes (2026-10-25). mc-verifier ends each report with a verify recipe: launch, seed data, widths, checks and setup traps, all from steps it ran. The main thread saves it in the app repo as .claude/skills/verify/SKILL.md, in the same PR: at mc-orchestrator Stage 4, or after a passing checked pass. cody and mc-verifier read it first, so no run works out the setup again. cody never edits it. It describes one app, so it is not a library copy.
  • Counts: unchanged. 18 agents (12 opus, 6 sonnet), 39 skills.
