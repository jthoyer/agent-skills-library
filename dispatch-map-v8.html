CPO Dispatch Map v8

Twenty-one agents. Two hubs, three lanes of work and eight single-pass specialists. A request enters CPO. CPO routes it to an agent, a pipeline or a skill, and grades the work after. COS sits above the library and routes into it.

What changed since v7

  • A strategy lane. strategy-challenger and strategy-juror joined on 2026-09-29, blind, behind the multi-actor-strategy skill. After run 1 both stay on trial, and juror cases no longer carry the challenger's verdicts.
  • mc-implementer folded into cody. cody now builds to the spec in the coding pipeline. The old file is archived unmodified in .claude/skills/_retired/.
  • The 2026-10-01 rule is withdrawn. A missing register in this repo cannot tell "unused" from "used where this repo can't see". A usage check on 2026-09-29 found no use, and the owner kept all three pipeline agents anyway.
  • The spec goes on disk before the build. mc-orchestrator Stage 2 waits for it, and the reviewer and verifier briefs carry its path.
  • Counts: 21 agents, 15 opus and 6 sonnet. multi-actor-strategy moved from the skills row to its own lane.

Since v8 (2026-10-02)

  • No agent changed. The map above still holds.
  • The two conducting skills tick a checklist. research-to-ideas (stages 0–8) and multi-actor-strategy (stages 1–4) open each run by pasting it, and a stage starts only when the one above is ticked.
  • A third library check in CI. scripts/check-skill-structure.sh: contents lists on long reference files, references one level deep, and a Requires: line for every skill script.
