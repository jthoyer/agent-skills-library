What each piece fixes

  • Challenger: the author of the preference no longer attacks it. The challenger picks the strongest option itself and attacks that one. If its pick differs from the preference, the recommendation must answer in writing.
  • Jurors: relabelling to A, B, C now hides something. In the baseline run the author knew every letter on sight, and its pick matched the preference.
  • Bets: jurors bet blind, so the bets can disagree. The baseline's three bets came from one mind and none disagreed.
  • Pre-mortem: built only if the re-run shows the risk step was the weakest. First check whether widening idea-challenger covers it.
  • .claude/skills/multi-actor-strategy/scripts/check_strategy.py: three or more options with sustain included, every option challenged, every eliminated option given a reason, a pre-mortem for every survivor, bets recorded, the pick gap answered, no Assumed rationale at Stage 4, and no "blind" claim on an embodied run. Each rule has a decoy that must fail in CI.
