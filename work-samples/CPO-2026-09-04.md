## Product decision reached
Blank = 0 for both boxes; explicit 0 in Seconds accepted; total of 0 still rejected. Rationale:
the prediction is one number split across two boxes for input convenience, so requiring both is an
input-format tax; whole-minute calls are the modal entry in a prediction race because people round.
A 0:00 call is not a real entry (absDelta would equal elapsed, guaranteed last), and an
accidentally-submitted empty form is far more likely than a deliberate 0:00, so rejecting costs a
real user nothing. But the two rejection paths need different copy.
